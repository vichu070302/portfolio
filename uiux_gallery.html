PROBLEM SOLVING

Key Design & Technical Bottlenecks Solved

01 / DISCOVERY FLOW

Complex Fragrance Selection

Fragrance notes (top, heart, base) often confuse online buyers. Solved by creating visual note sliders and interactive accord breakdowns in the Figma prototype.

02 / 3D PERFORMANCE

WebGL Canvas Mobile Lag

Heavy 3D meshes caused frame drops on mobile GPU. Solved by texture compression, optimized lighting passes, and dynamic canvas scaling.

03 / DESIGN SYSTEM

Fluid Component Tokens

Built a unified Figma library with reusable auto-layout components, color tokens, and elevation levels for consistent cross-platform scaling.
