PROBLEM SOLVING

Key Bottlenecks Solved in Lumina & Jakso

01 / PERF BOTTLE-NECK

Heavy Media Assets

Unoptimized high-resolution furniture imagery was slowing page render times. Solved by implementing lazy loading, WebP compression, and responsive image srcset pipelines.

02 / UI/UX BUG

Mobile Dropdown Offsets

Nested navbar padding was shifting mobile navigation dropdowns off-screen. Reengineered layout using `position: static` containers and `top: 100%` viewport anchors.

03 / THEME ENGINE

Dark/Light Mode Contrast

Hardcoded text colors resulted in white-on-white text during light mode toggle. Refactored all selectors to consume root CSS variables dynamically.
