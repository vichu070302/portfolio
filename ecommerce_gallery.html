UX Case Study · Lumina Furniture

Lumina Furniture E-Commerce

Designing a modern furniture shopping experience that helps users explore, evaluate, and purchase products with confidence.

Role: UI/UX Designer Type: E-commerce / Web Design Tools: Figma, HTML, CSS, JavaScript Platform: Responsive Web
OVERVIEW

Introduction & Context

Buying furniture online involves more consideration than simply choosing a product. Users need to evaluate the appearance, dimensions, materials, price and suitability of a piece before making a purchase.

For Lumina, I focused on creating a modern furniture e-commerce experience that makes product discovery easier and presents product information in a clear and visually engaging way.

THE CHALLENGE

How might we make furniture shopping online easier when users need to evaluate both aesthetics and practical information?

Furniture is a visual product, but users also need functional information. A successful furniture experience therefore needs to balance:

Visual Inspiration
Product Info
Easy Navigation
Purchase Confidence
THE PROBLEM

Key UX Challenges Identified

01 / CONSIDERATION

High-Consideration Purchase

Users need more information before purchasing compared with many everyday products.

02 / SCANNING

Quick Evaluation

When browsing multiple products, users should be able to understand basic differences without opening every page.

03 / SPECIFICATIONS

Product Details Matter

Dimensions, materials, pricing, and availability strongly influence a furniture purchase.

04 / VISUALS

Visual Presentation

Furniture needs strong imagery and a clean layout that allows products to remain the primary focus.

05 / MOBILE UX

Mobile Adaptability

Furniture websites contain large image grids that require careful adaptation for smaller screens.

TARGET USER

User Goals vs. Frustrations

User Goals
  • Discover furniture that matches their style
  • Compare multiple products easily
  • Understand dimensions, materials & specs
  • Complete checkout without friction
User Frustrations
  • Poor product organization & confusing navigation
  • Weak photography & missing dimensions
  • Unclear pricing & hidden delivery fees
  • Poor mobile grid performance
UX MATRIX

Problem → Solution Mapping

Identified UX Problem Applied UX Solution
Difficult to browse a large catalogue Clear categories and structured product grids
Users need to scan products quickly Consistent product cards with price & key badges
Important specifications can be overlooked Structured product-information hierarchy (dimensions, materials)
Furniture is highly visual Large, product-focused imagery with zoom capabilities
Users need purchase confidence Detailed product pages with availability & reviews
Mobile browsing can become difficult Responsive layouts and adaptive screen grids
Too many competing elements Strong visual hierarchy & generous whitespace
Checkout can create friction Simplified, multi-step progress checkout flow

REFLECTIONS & TAKEAWAYS

What I Learned

This project taught me that furniture e-commerce requires a careful balance between emotional design and functional information. Beautiful imagery can attract users, but clear information helps them make decisions.

"Good e-commerce UX connects what users want to see with what they need to know before making a purchase."
